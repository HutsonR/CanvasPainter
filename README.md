# Приложение «Рисовалка»

Простое Android-приложение, позволяющее рисовать пальцем на экране. Создано для демонстрации на мастер-классе по Android разработке.

## Функционал:
- Рисование пальцем с помощью `Canvas` и `Paint`.
- Минимальная и простая структура кода для лёгкого понимания новичками.

## Структура проекта:
- `MainActivity.kt` — основная Activity приложения, обработка UI и взаимодействий.
- `DrawingView.kt` — кастомный View для реализации рисования по экрану.
- `activity_main.xml` — макет интерфейса (кнопка сохранения и область рисования).

**Проект предназначен для быстрого старта изучения Android-разработки и идеально подходит для мастер-классов полностью начинающих.**
